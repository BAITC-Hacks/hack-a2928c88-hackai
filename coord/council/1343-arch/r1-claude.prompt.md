## Предложение codex

Предлагаю один FastAPI-процесс, одну HTML-страницу и SQLite. В checkout существуют `schemas.py`, `rating.py` и тесты; `agent.py`, `rules.py`, `llm.py`, `readers.py`, API и деплой предстоит создать. Подтверждение капитана принимаю из задания.

1. **Данные и хранение.** Сохраняем существующие Draft, TaskCard, TeamProfile, Proposal, Decision, AISuggestion. Расширяем CardContent структурированными подполями рубрики; обновляем CardField и подтверждения точного значения. FieldEvidence дополняем locator; Source хранит неизменяемый текст черновика, ответа или ручной правки. SQLite: drafts, sources, tasks, teams, proposals, progress_events. В tasks — редактируемая карточка, последний опубликованный снимок, revision, first_published_at. Отклик сохраняет снимок условий. Полной истории версий нет. Запись с устаревшей revision отклоняется.

2. **Единственная формула в `rating.py`.** Контекст/потребность 10+10; данные: материал 10, доступ 10 при подтверждённом материале; результат 15; успех: показатель/условие/проверка по 5 последовательно; ограничения 10; пользователи: группа/сценарий по 5; связь 4+3+3, последние компоненты требуют контакта. Неизвестное хранится как отсутствие значения, даёт 0. Баллы только за подтверждённые подполя; правка снимает подтверждение. Уровни сохраняем. Это оценка подтверждённой заполненности, не смысловой достоверности. Старую формулу заменяем одновременно с тестами и пересчётом seed.

3. **Конвейер.** `readers.py` превращает текстовые ответы в источники с локаторами; загрузку документов исключаем. `agent.py`: ввод → AI-предложение → проверки → редактирование → ручное подтверждение → рейтинг → публикация. `llm.py`: OpenAI Responses со Structured Outputs; схема AISuggestion содержит content, evidence, минимум три разных уместных questions. Первый вызов анализирует черновик, следующий извлекает ответы; отдельного AI-судьи нет. Максимальную прибавку возле вопроса вычисляет код. `rules.py` проверяет существование источника, точную цитату в указанном фрагменте, покрытие заполненных AI-полей доказательствами. Ошибка блокирует перенос поля; смысл пересказа проверяет человек. Ручная правка создаёт новый источник.

4. **Отказы.** Таймауты, ограничения размера/числа вызовов; OpenAI → NVIDIA с Pydantic-валидацией и одной попыткой исправления → маркированный mock. Заглушка задаёт вопросы по пробелам, не придумывает ответы. Trace показывает провайдера и live/partial/mock; промпт и контракт доступны для демонстрации.

5. **API и UI.** Операции черновика, уточнения, правки, подтверждения, публикации, каталога, отклика, решения и этапа. Русские экраны: конструктор с источниками и «было → стало», каталог с обоими фильтрами, предложения бизнеса. Сортировка: балл убывает, первая публикация и ID возрастают. Подтверждённая публикация доступна даже при 0; черновые правки не меняют опубликованный снимок. Выбор нуля/одной/нескольких команд ручной. +10 за подтверждённый этап выбранной команды: транзакция и UNIQUE(task, team, stage). Роли демонстрационные, без регистрации.

6. **Проверка и первый час.** Codex: backend/деплой; Claude: HTML через отдельный worktree с согласованным API. Две независимые задачи людям: проверить русские тексты; пройти демо по чек-листу. Gemini исключён. За первый час: контракт, расширенная рубрика, минимальный URL, проверка SQLite после перезапуска и одного AI-вызова. Docker, постоянный том, seed только пустой БД. Eval: цитата/отрицание/невалидный JSON/отказ API; тесты рейтинга, снимков, низкого балла, множественного выбора и конкурентного начисления. Сохраняем synthetic-набор 5×4. Затем сквозной smoke, README, disclosure, checkpoint.

Не делаем чат, ML-рекомендации, автоназначение, файловое хранилище, полный трекер.
