## Предложение codex

**«Sana: Паспорт готовности»** — превращаем короткую бизнес-задачу в подтверждённую карточку, где каждый балл объясним, а каждое заполненное AI поле связано с исходным ответом.

**Пользователь и боль:** предприниматель пишет «нужен бот», студенты не понимают результат, доступные данные и условия приёмки. Вход: черновик и ответы бизнеса. Выход: редактируемая карточка, прозрачный рейтинг, публикация, предложения команд и ручное решение.

**Пять отличий и бюджет — 210 минут, включая проверку и деплой:**

1. **AI-интервью с объяснением пользы — 40 минут.** Агент анализирует пробелы, задаёт минимум три уместных вопроса, показывает, какой раздел заполнит ответ. Вопросы про данные, результат и измеримый успех приоритетнее косметики. Неизвестное остаётся неизвестным.

2. **«Откуда это взялось?» — 35 минут.** В MVP AI возвращает ссылки на фрагменты пользовательского текста; сервер заполняет фактические поля самими фрагментами. Нажатие показывает источник и цитату. Несуществующий фрагмент отклоняется. Свободное перефразирование откладываем: совпадение цитаты само по себе не доказывает корректность пересказа. Человек редактирует и подтверждает поля; правка снимает подтверждение и публикацию.

3. **«Следующий шаг: +15» — 35 минут.** Код считает рейтинг по весам кейса: 20/20/15/15/10/10/10, с дроблением из scoring-07. Показываем начисления, недостающее и прирост после подтверждения. Рейтинг означает заполненность, не достоверность или ценность бизнеса. Вау-момент: подтверждённое дополнение меняет уровень и место карточки.

4. **Открытый выбор с видимым результатом — 55 минут.** Каталог с сортировкой и фильтрами; даже опубликованная карточка с 0–39 баллами принимает отклики. Предложение содержит идею, план, срок и ссылку. Бизнес выбирает одну, несколько или ни одной команды. Один вручную подтверждённый этап начисляет отдельные баллы прогресса, повторное подтверждение их не удваивает.

5. **Проверяемая демонстрация — 45 минут.** Синтетические примеры, тесты инвариантов, README, деплой и проверка URL. При отказе API — явно обозначенный mock; показываем промпт, структуру ответа и отклонение некорректного результата.

**Шаги агента:** определить пробелы → задать вопросы → привязать ответы к полям → вызвать проверки → показать карточку человеку. Код проверяет структуру, источники, подтверждения, арифметику и переходы состояний. Человек подтверждает содержание, публикацию, выбор и этап.

**Данные сегодня:** кейс доступен; готовый набор в проверенных `data/` и `eval/` отсутствует. Подготовим маркированную синтетику: по пять черновиков, карточек, команд и предложений.

**Метрика и бейзлайн:** на одинаковых пяти черновиках сравним с одним запросом «составь карточку»: число неподкреплённых полей, покрытие пропусков, время до подтверждения. Цели: ноль неподкреплённых опубликованных AI полей, точный рейтинг во всех тестах, работающие переходы. Измерений пока нет. Преимущество — проверяемое состояние и действия после ответа модели.

**Демо, 60 секунд:** слабый черновик → три вопроса → подготовленные ответы → источник поля → подтверждение и рост рейтинга → каталог → отклик → ручной выбор.

**Пилот:** предложить координатору AI Sana испытание с пятью бизнесами и пятью командами; договорённостей пока нет.

**Не делаем:** авторизацию, чат, рекомендации команд, автоматическое назначение, ML, полный трекер.

**IDEA_SCORING:** соответствие 5, боль 5, реализуемость 3, данные 4, проверяемость 5, агентность 4, пилот 3, демо 5; **107/135**. Главный риск — интеграция и деплой за оставшееся время.

## Предложение claude

**Название:** «Карточка с доказательствами» (Proof-Card Hub)

**Одна фраза:** Бизнес видит, сколько баллов и мест в каталоге даёт каждый ответ, а у каждого поля карточки есть цитата из его собственных слов. Поле без цитаты код не заполняет и не засчитывает.

**Пользователь и боль.** Представитель бизнеса пишет «нужен чат-бот для клиентов» и не понимает, чего не хватает. Студенты не могут оценить, реально ли взяться за задачу.

**Вход → выход.** Черновик (1–3 строки) → ≥3 вопроса с ценой в баллах → редактируемая карточка из 10 полей, у каждого поля есть источник → рейтинг 0–100 с расшифровкой → позиция в каталоге → отклики → ручной выбор бизнеса → баллы команде за подтверждённый этап.

**Шаги агента:**
1. LLM extract: поля карточки плюс `evidence` (дословная цитата из черновика или ответа).
2. Код, правило R-QUOTE: если цитаты нет во входе, поле пустое, 0 баллов, пометка «ИИ предложил, отклонено».
3. LLM задаёт вопросы только по пустым полям. Код считает цену каждого вопроса (+N баллов, место #6 → #2).
4. Человек правит карточку и подтверждает поля. Правка снимает подтверждение, после неё код пересчитывает рейтинг.
5. Публикация, отклик команды, бизнес выбирает вручную (одну, несколько или никого).

**Что проверяет код:** веса 20/20/15/15/10/10/10, уровни готовности, сортировку и фильтры каталога, R-QUOTE, «баллы только за подтверждённые поля», запрет авто-назначения, ≥3 вопроса.

**Что подтверждает человек:** каждое поле карточки, публикацию, выбор или отклонение отклика, выполнение этапа.

**5 отличий (оценка времени):**
1. **Чипы-доказательства + R-QUOTE** (40 мин). Наведи на поле — видна цитата и её источник. Счётчик «ИИ отклонено: N выдумок» даёт прямое доказательство критерия «без выдуманных данных».
2. **Цена вопроса** (30 мин). Возле каждого вопроса: «+20 баллов → уровень Рабочая → место #2». Код симулирует ранг, это главный элемент геймификации (25 баллов).
3. **Лента рейтинга** (40 мин). Полоски по 7 критериям, дельта после каждого подтверждения, бейдж уровня, «призрак» позиции в каталоге.
4. **Сравнение откликов** (45 мин). Отклики бок о бок, кнопки «выбрать / отклонить / никого», подтверждение этапа, баллы прогресса команде.
5. **Eval честности** (30 мин). 5 синтетических черновиков с ловушками (нет данных, размытые сроки). Сравниваем обычный промпт «заполни карточку» и наш пайплайн по доле выдуманных полей и покрытию цитатами. Отчёт `eval/report.md` со ссылкой из README.

Итого ≈3 ч 05 мин, запас ≈25 мин.

**Данные на сегодня:** честная синтетика с пометкой в UI и README: 5 черновиков, 5 карточек, 5 команд, 5 откликов.

**Метрика и бейзлайн:** выдуманные поля: бейзлайн — сырой промпт (замер на eval), цель — 0% после R-QUOTE. Покрытие подтверждённых полей цитатами — 100%. Рост рейтинга в демо: 15 → 75+.

**Чем лучше обычного запроса к модели.** Модель охотно дописывает «данные: CRM за 2 года», которых пользователь не называл. У нас это ловит код, а не промпт. Рейтинг и позицию считает код, модель только формулирует вопросы.

**Демо за 60 секунд:** «нужен бот для клиентов» → рейтинг 15, «Черновик», место #6 → ИИ пытается выдумать поле «данные», R-QUOTE его отклоняет (видно) → 3 ответа с ценой → 78, «Готовая», место #2 → публикация → команда откликается → бизнес выбирает одну команду и отклоняет вторую → этап подтверждён, команде +баллы.

**Путь к пилоту:** модуль приёма задач для AI Sana/МНВО, вуз-партнёры как первые площадки. Бизнес-заявки из существующих форм сразу проходят через этот конструктор.

**Что НЕ делаем:** auth и роли, чат, уведомления, векторный поиск, ML-рекомендации (рекомендации строим по пересечению навыков и тегов, без чувствительных признаков), ранжирование откликов ИИ, оценку бизнес-ценности задачи, мобильную вёрстку.

**Самооценка по IDEA_SCORING:** кейс 5×3=15, боль 4×3=12, реализуемость 4×5=20, данные 5×4=20, проверяемость 4×3=12, агентность 4×3=12, пилот 4×4=16, вау 4×2=8. **Итого 115/135.**

**Риск:** R-QUOTE может отбрасывать перефразы. Решение: нечёткое совпадение по нормализованному тексту, а при несовпадении поле уходит в ручное подтверждение, а не молча отбрасывается.
