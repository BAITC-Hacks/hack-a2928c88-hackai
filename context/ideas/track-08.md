# Идея — трек 8: Образование

Черновик по шаблону `IDEA_CANVAS.md`. Основан на рабочей гипотезе из `claude_8.md` (21.09.2026). **Не официальный кейс** — после получения кейса сверить и переписать (prompts/00-kickoff.md).

## Название
TaskGuard — проверка учебного задания перед публикацией

## Пользователь и боль
- Кто: Учитель / методист
- Боль: <что делает сейчас, сколько времени, где ошибается — заполнить из кейса>

## Одна фраза решения
«<Пользователь> загружает <вход>, агент <действие> и возвращает <выход с доказательствами>, пользователь подтверждает, в результате <измеримый эффект>.» — заполнить после чтения кейса.

## Вход → выход
- Вход: Фрагмент учебного материала + задание + ключ ответа
- Выход: Замечания: несоответствие источнику, неоднозначность вопроса, ошибка в ключе — с цитатой

## Шаги агента
1. Извлечь вопросы и ключи
2. Модель проверяет ответ по источнику
3. Код: формат, число вариантов, единственность правильного
4. Учитель принимает/исправляет, экспорт

## Что проверяет код (app/rules.py)
- ровно один правильный вариант
- ключ есть среди вариантов
- длина/формат задания

## Проверка
- Набор: 20–30 заданий с заложенными ошибками, разметка учителя; recall ошибок
- Бейзлайн: генератор без проверки / один запрос

## Не заявлять
соответствие всей программе; экономию времени без замера

## Запасные идеи трека
- Проверка развёрнутых ответов по рубрике с объяснением (учитель финализирует)
- Адаптация текста под уровень ученика KZ/RU
