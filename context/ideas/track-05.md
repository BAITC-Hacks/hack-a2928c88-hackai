Черновик по шаблону `IDEA_CANVAS.md`. Основан на рабочей гипотезе из `claude_5.md` (21.09.2026). **Не официальный кейс** — после получения кейса сверить и переписать (prompts/00-kickoff.md).

## Название
MedDocCheck — полнота медицинского документа

## Пользователь и боль
- Кто: Сотрудник по качеству медицинской документации
- Боль: <что делает сейчас, сколько времени, где ошибается — заполнить из кейса>

## Одна фраза решения
«<Пользователь> загружает <вход>, агент <действие> и возвращает <выход с доказательствами>, пользователь подтверждает, в результате <измеримый эффект>.» — заполнить после чтения кейса.

## Вход → выход
- Вход: Искусственная (синтетическая) медицинская запись одного типа + набор обязательных правил
- Выход: Пропущенные обязательные поля, внутренние противоречия (даты, дозировки, коды), ссылка на правило; проверяющий подтверждает

## Шаги агента
1. Извлечь поля записи
2. Код: обязательные поля, порядок дат, формат кодов МКБ
3. Модель ищет смысловые противоречия
4. Проверяющий подтверждает замечания

## Что проверяет код (app/rules.py)
- обязательные поля заполнены
- дата выписки ≥ даты поступления
- код МКБ-10 валидного формата

## Проверка
- Набор: 15–20 синтетических записей с заложенными ошибками; recall ошибок
- Бейзлайн: один запрос «проверь документ»

## Не заявлять
клиническую эффективность; диагноз/лечение/решение об оплате

## Запасные идеи трека
- Подготовка выписки из записей врача с цитатами
- Навигатор пациента по маршруту обследования (без медсоветов)
