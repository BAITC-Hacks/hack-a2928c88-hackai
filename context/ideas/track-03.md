## Название
GeoEvidence — извлечение фактов из геоотчётов

## Пользователь и боль
- Кто: Геолог / специалист геологического архива
- Боль: <что делает сейчас, сколько времени, где ошибается — заполнить из кейса>

## Одна фраза решения
«<Пользователь> загружает <вход>, агент <действие> и возвращает <выход с доказательствами>, пользователь подтверждает, в результате <измеримый эффект>.» — заполнить после чтения кейса.

## Вход → выход
- Вход: Страницы разрешённого геологического отчёта одного формата (текст/OCR)
- Выход: Таблица объектов (скважины, координаты, запасы, интервалы) со страницей, цитатой и уверенностью; сомнительное — на ручную проверку

## Шаги агента
1. OCR/текст по страницам
2. Модель извлекает поля в схему
3. Код проверяет координаты, единицы, суммы интервалов
4. Специалист подтверждает, экспорт CSV

## Что проверяет код (app/rules.py)
- координаты в допустимом диапазоне РК
- единицы измерения согласованы
- глубина «от» < «до»

## Проверка
- Набор: 10–20 страниц с ручным эталоном; точность по полям
- Бейзлайн: ручная выписка / один запрос к модели

## Не заявлять
прогноз месторождения; точность на всём архиве
