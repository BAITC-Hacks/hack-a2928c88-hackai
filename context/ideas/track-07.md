## Одна фраза решения
«<Пользователь> загружает <вход>, агент <действие> и возвращает <выход с доказательствами>, пользователь подтверждает, в результате <измеримый эффект>.» — заполнить после чтения кейса.

## Вход → выход
- Вход: Разрешённый или синтетический набор транзакций (CSV)
- Выход: Цепочки переводов с причинами выделения, хронология, карточка для ручного рассмотрения

## Шаги агента
1. Построить граф переводов (код, networkx)
2. Правила: дробление, транзит за короткое время, круговые переводы, новые счета
3. Модель пишет объяснимую карточку
4. Аналитик решает, экспорт

## Что проверяет код (app/rules.py)
- дробление ниже порога
- транзит < N минут
- цикл A→B→C→A

## Проверка
- Набор: синтетический граф с заложенными схемами (помечен как синтетика); recall схем
- Бейзлайн: фиксированные пороги без графа

## Не заявлять
эффективность реального антифрода; блокировку счетов
