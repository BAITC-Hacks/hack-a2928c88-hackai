## Название
FieldCard — карточка наблюдений по участку

## Пользователь и боль
- Кто: Аналитик / инспектор земельного контроля
- Боль: <что делает сейчас, сколько времени, где ошибается — заполнить из кейса>

## Одна фраза решения
«<Пользователь> загружает <вход>, агент <действие> и возвращает <выход с доказательствами>, пользователь подтверждает, в результате <измеримый эффект>.» — заполнить после чтения кейса.

## Вход → выход
- Вход: Полигон участка + снимки Sentinel-2 за несколько дат (NDVI) + сведения о качестве (облачность)
- Выход: График NDVI, ссылки на сцены, ограничения, вопросы для выездной проверки

## Шаги агента
1. Загрузить сцены по полигону (код)
2. Код: NDVI, маска облаков, изменение между датами
3. Модель формулирует наблюдения и вопросы
4. Инспектор подтверждает, экспорт карточки

## Что проверяет код (app/rules.py)
- облачность сцены < порога
- изменение NDVI > порога
- сезонность (сравнение с прошлым годом)

## Проверка
- Набор: 2–3 демонстрационных участка за сезон; сверка с визуальным осмотром снимков
- Бейзлайн: визуальный просмотр снимков вручную

## Не заявлять
доказанное нарушение землепользования по одному индексу
