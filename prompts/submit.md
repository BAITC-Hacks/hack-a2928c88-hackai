# Подача

1. Пройди `docs/SUBMISSION_CHECKLIST.md` пункт за пунктом; для каждого — доказательство (команда/файл).
2. `python scripts/smoke_url.py <URL>` — ссылка должна работать без нашего ноутбука.
3. Прогони `prompts/judge.md`; исправь всё, что стоит < 10 минут.
4. Сверь README с шаблоном `docs/README_TEMPLATE.md`: ни одного TODO, ссылка и доступы на месте, раздел «Ограничения» честный.
5. Финальный чекпоинт и тег `submission`.
6. Выведи текст для формы подачи: название, 1 абзац описания, URL, репозиторий, доступы.
