# Почасовой чекпоинт (п. 6.6 регламента)

Для часа N:
1. `git status`, `git log --oneline -10` — что сделано за час.
2. `python -m pytest -q`; если есть URL — `python scripts/smoke_url.py <URL>`.
3. Сформулируй ОДНУ проверяемую фразу результата часа (что можно открыть/запустить). Не «работали над…», а «эндпоинт /api/run возвращает находки с цитатами на 3 примерах».
4. Обнови чек-лист плана часа в `docs/IDEA.md` → «План по часам».
5. Запусти `scripts/checkpoint.ps1 -Hour N -Note "<фраза>"` (или `.sh N "<фраза>"`).
6. Если отстаём от плана — предложи, что вырезать из MVP, и запиши в «Decisions».

Ориентир по часам:
- Ч1: кейс разобран, каркас под домен, первый деплой.
- Ч2: основной сценарий end-to-end на реальном примере.
- Ч3: доказательства, обработка ошибок, подтверждение человеком, 2+ правила.
- Ч4: eval на наборе + сравнение с бейзлайном, цифры в README.
- Ч5 (финиш за 30 мин до дедлайна): README, демо-сценарий, smoke по URL, подача.
