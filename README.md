# Sana Hub — «Паспорт готовности»

**HackAlem AI · трек 07 «Образование» · AI Sana Challenge Hub**

**Демо:** [sana-hub-0ca1dc1.onrender.com](https://sana-hub-0ca1dc1.onrender.com/) · [API](https://sana-hub-0ca1dc1.onrender.com/docs). Сейчас доступны backend и каталог, режим mock; экран бизнеса ещё ожидается.

## 1. Что делает проект

Sana Hub помогает бизнесу превратить описание проблемы в задачу для студентов: уточняющие вопросы → карточка с цитатами → подтверждение человеком → прозрачный рейтинг → публикация → отклики → ручной выбор команды → баллы за подтверждённый этап.

Бизнес видит, каких сведений не хватает и за что начислены баллы. AI не выбирает команду и не подтверждает факты. Низкий рейтинг не запрещает публикацию подтверждённой карточки и получение откликов.

Официальный кейс: [docs/CASE.md](docs/CASE.md). Идея: [docs/IDEA.md](docs/IDEA.md).

## 2. Что реализовано

| Компонент | Состояние |
|---|---|
| Модели и рейтинг 0–100 | Работают, баллы только за подтверждённые значения |
| HTTP API и SQLite | Сквозной сценарий проверен тестами |
| Карточка и публикация | Правка снимает подтверждение; каталог хранит опубликованный снимок |
| Каталог | Фильтры по отрасли и уровню, сортировка по рейтингу |
| Отклики и решения | Бизнес вручную выбирает несколько команд или отклоняет все |
| Прогресс | +10 за подтверждённый этап; повторное начисление запрещено по задаче и команде |
| AI | OpenAI gpt-4.1-mini проверен реальными запросами локально; NVIDIA — непроверенный резерв; явный mock |
| Источники | Только дословные цитаты; R-QUOTE отклоняет отсутствующий источник или цитату |
| Данные | Пять синтетических черновиков, карточек, команд и откликов |
| Интерфейс | Оба экрана интегрированы; полный локальный сценарий проверен в Edge с live OpenAI и mock |
| Публичный деплой | Render доступен; API и загрузка каталога проверены по публичному URL |

Действующая формула в [app/rating.py](app/rating.py):

| Критерий | Баллы | Поля |
|---|---:|---|
| Контекст и потребность | 20 | context 10 + need 10 |
| Данные и материалы | 20 | data |
| Ожидаемый результат | 15 | expected_result |
| Критерии успеха | 15 | success_criteria |
| Ограничения | 10 | constraints |
| Пользователи | 10 | users |
| Связь с бизнесом | 10 | contact 4 + interaction_format 3 + feedback_process 3 |

Уровни: 0–39 «Черновик», 40–69 «Рабочая», 70–89 «Готовая», 90–100 «Приоритетная». Название не даёт баллов. Подтверждение относится к точному значению; после изменения оно снимается. Расширенные подполя отложены, в проекте одна формула.

## 3. Технологии и архитектура

Python 3.10+ (проверено на 3.10), FastAPI/Uvicorn, Pydantic v2, SQLite, OpenAI SDK, Vanilla JS без сборки Node. Проверки: pytest и TestClient/httpx. Точные версии — requirements.txt и requirements-dev.txt. Docker использует Python 3.12.

```text
Экраны бизнеса / каталога → app/static/api.js → FastAPI
                              ├─ app/llm.py: извлечение цитат и вопросы
                              ├─ app/rating.py: формула и подтверждения
                              └─ app/store.py: SQLite, транзакции и снимки
```

`If-Match` защищает правки от устаревшей версии. Отклик сохраняет условия опубликованной карточки. Уникальная запись этапа по задаче/команде исключает повторные +10 в одной транзакции. Баллы готовности и прогресса разделены.

Исторический context/track-07 относится к финтеху; актуальное задание — только docs/CASE.md.

## 4. Установка и запуск

Нужны Git и Python 3.10+. Команды из корня репозитория.

```powershell
git clone https://github.com/BAITC-Hacks/hack-a2928c88-hackai.git
cd hack-a2928c88-hackai
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
# Только при первом запуске: не перезаписывайте существующий .env
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Linux/macOS: `python3 -m venv .venv`, затем те же команды через `./.venv/bin/python`; копирование — `cp .env.example .env`.

Открыть http://127.0.0.1:8000 и документацию API http://127.0.0.1:8000/docs. Доступны экран бизнеса и вкладка «Каталог и команды». Публичный Render обновляется отдельно от локальной версии.

По умолчанию `MOCK=1`, `SEED_DEMO=1`: ключи не нужны. База `data/runtime/sana.sqlite3` сохраняется между запусками, синтетические записи загружаются один раз. Для чистой базы задайте другой DATABASE_PATH.

Для реального OpenAI задайте в локальном .env `OPENAI_API_KEY`, `OPENAI_MODEL=gpt-4.1-mini`, `MOCK=0`; перезапустите сервер. Проверка одним платным запросом на синтетике: `python scripts/check_ai.py`. Ключ не выводится. Для Render эти значения отдельно задаются в Environment; локальный .env туда не переносится.

Полный локальный браузерный сценарий: установите дополнительный инструмент `pip install playwright==1.63.0` (нужен установленный Edge), затем `python scripts/smoke_e2e.py --url http://127.0.0.1:8000 --mode mock`. Для сервера с MOCK=0 используйте `--mode live`: это два реальных AI-запроса. Скрипт создаёт учебные записи и разрешает только localhost. Проверенный результат: 0 → 100 → 80 → 100, публикация, новый отклик, ручной выбор, однократные +10.

Docker:

```bash
docker build -t sana-hub .
docker run --rm -p 8000:8000 -v sana-data:/data -e MOCK=1 sana-hub
```

Docker-образ собран, запуск контейнера и read-only API smoke проверены локально. Шаблон render.yaml без постоянного диска использует временное хранилище — для сохранения данных подключите диск к /data.

## 5. Пример проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pytest tests/test_api.py -q
```

API-тест проходит создание черновика → вопросы → ответы → карточку с нулём баллов → подтверждение → публикацию → редактирование со снятием подтверждения. Проверяет низкий рейтинг, отклик, ручной выбор нескольких команд, однократные +10, сохранение базы после перезапуска. Тесты не доказывают готовность экранов или публичного URL.

Короткая проверка формулы:

```powershell
.\.venv\Scripts\python.exe -c "from app.schemas import TaskCard; from app.rating import calculate_rating, confirm_fields, edit_card; c = TaskCard(draft_id='demo', industry='retail', context='Requests by email', data='Synthetic CSV', synthetic=True); print(calculate_rating(c).total); c = confirm_fields(c, ['context', 'data'], business_actor='demo-business'); print(calculate_rating(c).total); c = edit_card(c, {'context':'Requests by phone'}); print(calculate_rating(c).total)"
```

Результат: **0 → 30 → 20**. Подтверждение добавляет баллы, правка снимает баллы изменённого поля.

В `/docs` действия бизнеса требуют `X-Demo-Role: business`, отправка отклика — `team`. Для правки, подтверждения и публикации передайте `If-Match`, равный `revision` карточки. Адаптер api.js делает это автоматически. Это демонстрационные роли, а не настоящий логин.

## 6. Данные и внешние сервисы

[data/samples/ai-sana-synthetic.json](data/samples/ai-sana-synthetic.json): по пять записей каждого типа, пометка `synthetic: true`. Организации, контакты и команды вымышлены. example.com — демонстрационные ссылки. Готовые карточки — учебные эталоны с подтверждениями автора фикстур, не автоматически подтверждённый AI-вывод. Рейтинги: T1 49, T2 34, T3 67, T4 82, T5 100.

При `MOCK=0` используется OpenAI Responses Structured Outputs; при ошибке — NVIDIA chat completions, затем mock, если `FALLBACK_TO_MOCK=1`. Ключи только в окружении/.env. При отсутствии ключей оставьте MOCK=1. Внешним сервисам передаются введённый текст и ответы бизнеса. 23.09 проверены реальные вопросы и сборка карточки через OpenAI локально, provider=openai. NVIDIA и live AI на Render пока не подтверждены.

Промпт, схема обмена и правило R-QUOTE находятся в [app/llm.py](app/llm.py). [Документация OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs). Лимиты: 30 000 символов суммарного входа, MAX_CALLS_PER_HOUR запросов в процессе; таймаут AI_TIMEOUT_SECONDS на запрос провайдера.

Предсуществующий harness, модели и библиотеки раскрыты в [docs/DISCLOSURE.md](docs/DISCLOSURE.md). Инструменты разработки Codex/Claude не являются продуктовой AI-функцией. Gemini недоступен.

## 7. Известные ограничения

- В main оба экрана работают; публичный Render пока на прежнем образе без business.js. Требуется сменить образ и настройки Environment.
- Рейтинг измеряет подтверждённую заполненность: слабое или неправдивое описание тоже может получить баллы. Семантическая оценка не заявляется.
- Совпадение цитаты не доказывает смысл и уместность поля; результат проверяет человек. Mock переносит текст и ответы по полям, не выполняет интеллектуальный разбор.
- Роли открыты для демо, нет аутентификации и изоляции компаний. Используйте учебные данные.
- SQLite и лимит вызовов рассчитаны на один процесс. В контейнере нужен постоянный том.
- Повторная сборка черновика возвращает уже созданную карточку; дальнейшие правки выполняются через редактор.
- Нет readers файлов, чата, календаря, полного трекера и автоматического выбора исполнителя. Текущий ввод — текст.
- Форма каталога пока называет ссылку необязательной, но API требует HTTP(S) URL; при пустой ссылке показана понятная ошибка. Замечание передано в ревью T-002.
- Полный сценарий проверен локально автоматизированно; очная репетиция за пять минут и проверка обновлённого публичного сервиса ещё нужны.
