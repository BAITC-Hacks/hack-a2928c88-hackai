# AI Sana Challenge Hub — основа MVP

Трек 07 «Образование». Официальный кейс: [docs/CASE.md](docs/CASE.md).
Сейчас реализованы **схемы и рейтинг**, а не готовое веб-приложение.
Идея ожидает подтверждения капитана; API, UI и деплой ещё не готовы.

## Проверка основы

Python 3.10+ (проверено на 3.10):

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt
.venv/Scripts/python.exe -m pytest -q
```

`app/schemas.py`: Draft, TaskCard, RatingBreakdown, TeamProfile, Proposal, Decision.
`app/rating.py`: веса 20/20/15/15/10/10/10, уровни 0–39/40–69/70–89/90–100.
Только непустое поле, совпадающее с точным значением человеческого подтверждения,
получает баллы. Редактирование снимает подтверждение. AI-ответ не содержит полномочий
подтверждать или выбирать команду. Это доменный контракт; проверка прав в API ещё не реализована.

Детализация основы: контекст/потребность по 10; связь — контакт 4, консультации 3,
обратная связь 3. Остальные поля оцениваются целиком. Формула измеряет подтверждённую
заполненность, не истинность фактов; уточнение семантических подполей вынесено на совет.

[Синтетический набор](data/samples/ai-sana-synthetic.json): по 5 черновиков, карточек,
команд и откликов. Карточки — ручной учебный эталон, **не автоматически подтверждённый
вывод AI**. Ссылки example.com демонстрационные. Рейтинги вычислены кодом.
