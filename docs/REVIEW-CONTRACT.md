# Проверка карточки перед стартом

Реализована по поручению капитана 23.09.2026 после интеграции PR #3. Codex изменил экран бизнеса для этой задачи; файлы каталога участника не менялись. Claude не вызывался.

`POST /api/cards/{id}/review`, заголовки `X-Demo-Role: business` и `If-Match: <revision>`, без тела. В адаптере: `api.reviewCard(id)` → CardView с `review`.

`review = {status, revision, mode, provider, issues:[{field, kind, quote, message, question}]}`. Status: not_run, complete, stale. Mode: live/mock либо null до проверки. Kind: rule/ai. Пустая цитата допустима только для проверки пустого поля кодом. На сбое без fallback API отвечает 503, не перезаписывая карточку; UI показывает недоступность и повтор. При конфликте revision — 409, при отсутствии If-Match — 428.

Проверка не повышает revision, не подтверждает поля и не меняет текст/баллы. Результат сохраняется только если revision не изменился за время запроса. При текстовой правке анализ устаревает; подтверждение или публикация неизменённого текста переносит актуальный анализ на новую revision. Старые записи SQLite без review читаются как not_run; миграция схемы не нужна.

Каталог возвращает `catalog_insights` по контракту TASK-02-INNOVATION.md. Review берётся из опубликованного снимка; анализ рабочего черновика не виден командам до публикации. Ответ publish тоже содержит insights для немедленного focusCard в UI. Место глобальное, независимо от фильтров и страницы, с теми же правилами равенства баллов. Действия используют веса RUBRIC и недостающие подтверждения; изменение любого одного поля рассматривается отдельно.

Границы: факт наличия цитаты не доказывает смысловую корректность вывода; модельные замечания показаны как предположения. Mock проверяет только пустые поля и небольшой список фраз отложенного уточнения. Не моделирует семантическую проверку. Общий рейтинг и доступность публикации/откликов от review не зависят.

Проверено: 59 pytest, smoke_review и полный mock smoke_e2e в Edge; отдельный live OpenAI probe на синтетическом несоответствии годовых данных и месячного прогноза, две проблемы (одна правилом, одна AI), цитаты валидированы. На Render новая функция пока не проверена.
