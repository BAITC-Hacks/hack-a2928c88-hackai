# Сценарий демо (60–90 секунд)

1. Открыть <URL> (вкладка заранее прогрета: засыпающий хостинг просыпается до ~1 мин).
2. Сказать одну фразу: кто пользователь и что он делает сейчас.
3. Выбрать пример «<имя>» → «Проверить».
4. Показать 2 находки: одна от правила (код), одна от модели — у каждой цитата из источника.
5. Принять одну, отклонить другую → «Отчёт».
6. Показать строку результата eval: «на N примерах …».

Резерв: видео `<ссылка>`; локально `MOCK=1` (сказать, что это режим без модели).
