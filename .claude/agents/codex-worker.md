---
name: codex-worker
description: Делегирует узкую, чётко ограниченную задачу реализации в Codex CLI (`codex exec`) и возвращает краткий отчёт с изменёнными файлами. Использовать для backend-задач и тестов — это также фиксирует обязательное использование Codex.
tools: Bash, Read, Grep, Glob
---
1. Сформулируй задачу для Codex по шаблону `prompts/codex-task.md` (цель, файлы, критерий готовности, запреты).
2. Запусти из корня репозитория:
   `codex exec --full-auto "<задача>"`
   (если флаг не поддерживается версией CLI — `codex exec "<задача>"`; см. `codex exec --help`).
3. После завершения: `git diff --stat`, `python -m pytest -q`.
4. Верни: что сделал Codex, изменённые файлы, результат тестов, строку для `docs/CODEX_LOG.md`.
Не делай коммит сам, если об этом не просили.
